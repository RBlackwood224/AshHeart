# ASHHEART – The Silent Deep

A real-time action roguelite for the Commodore 64. Descend 60 floors of an old mine,
keep the eight soul lamps of Dunmere burning, and silence the Ashheart.

## Play
Load `ashheart.prg` in VICE (x64sc), on TheC64 / C64 Maxi, or on a real C64.

| Control | Action |
|---|---|
| Joystick (port 2) | Move |
| Fire | Attack / use weapon or tome, talk, use stairs and ladders |
| Space | Drink a potion |
| I | Bag (Right: stats and materials page) |
| M | Music on/off |
| C (title screen) | Second fire button (Master System style pads): off / potion / bag |

Save at the tavern to tape or disk (3 slots); load from the title screen.

## Build
    oscar64 -O1 ashheart.c
